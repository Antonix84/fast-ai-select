# Changelog

Все заметные изменения плагина Fast AI Select.
Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [Semantic Versioning](https://semver.org/lang/ru/).

## [1.1.5] — 2026-11-12

### Исправлено

- Команды больше не могут навсегда остаться занятыми из-за незавершённого
  Promise: добавлены watchdog-таймауты, инвалидация зависшей ORT-сессии,
  идентификатор операции и очистка состояния при выгрузке плагина.
- Guided filter теперь вычисляет каждый полноразмерный пиксель. Небезопасное
  заполнение целых блоков по усреднённой яркости удалено: оно могло удалять
  тонкие волосы и создавать жёсткие артефакты.
- Контраст мата применяется к float-значениям до квантования, снижен с 2 до
  1.4 и больше не уничтожает слабую полупрозрачную альфу.
- Исходная alpha больше не применяется дважды к маске слоя. Для полупрозрачных
  RGBA-слоёв порядок теперь: matte → контраст → alpha → 8 бит.
- Исправлен режим 768: он больше не подменяется на 384.
- Изображение масштабируется с сохранением пропорций и letterbox; уменьшение
  RGB и alpha использует дробное area-усреднение, увеличение — билинейную
  интерполяцию.
- Пиксели запрашиваются в sRGB. Для «Удалить фон» читается целевой слой, а не
  composite всего документа. Если во время расчёта пользователь переключил
  документ, запись безопасно отменяется.
- Радиус guided filter адаптируется к масштабу сетевого мата (4–16 px).
- Background-слой преобразуется только после успешного расчёта маски; при
  пустой маске документ не изменяется.
- Резервное удаление пикселей явно выбирает целевой слой и снимает выделение
  даже при ошибке.
- Установщик собирает и проверяет копию во временной папке, делает резервную
  копию, обновляет `PS.json` атомарно и сохраняет остальные поля и записи
  других плагинов. Повреждённый `PS.json` больше не перезаписывается.

### Тесты

- Добавлены проверки letterbox, bilinear/area-ресайза, частичной RGBA-альфы,
  точности guided filter на нерегулярных размерах и контрасте, режима 768,
  сброса `busy`, отмены после выгрузки и целостности установки.

## [1.1.4] — 2026-11-12

### Изменено

- Вход сети по умолчанию поднят с 384 до 512 px: более детальный мат на волосах
  и мелких краях. Для скорости можно вернуть 384 в `plugin/index.js`.
- В консоль при загрузке пишется версия плагина и размер входа.

## [1.1.3] — 2026-11-12

### Исправлено

- Широкий «растушёванный» край: радиус guided filter теперь задаётся в пикселях
  полного разрешения и делится на коэффициент субдискретизации (8 px вместо
  ~32 px).
- Белый ореол вокруг одежды: добавлен контраст мата (×2) вокруг 0.5.
- Установка при открытом Photoshop больше не выполняется: папка загруженного
  плагина заменялась, и плагин исчезал из меню.
- Из резервного пути удалён `fill` с `backgroundColor`, который мог залить фон
  цветом фона вместо прозрачности.

## [1.1.2] — 2026-11-12

### Изменено

- «Удалить фон» теперь добавляет маску слоя через `imaging.putLayerMask`
  (белое — человек виден, чёрное — фон скрыт). Это не зависит от доступности
  команды «Удалить» и не разрушает пиксели.
- Резервный путь: выделение → инверсия → `delete` → снятие выделения,
  разнесённый по отдельным модальным областям.

## [1.1.1] — 2026-11-12

### Исправлено

- «Удалить фон» падал на любом слое: `Layer.kind` в Photoshop 2025 приходит
  строкой (`pixel`, `background`, `smartObject`), а не числом. Тип слоя теперь
  нормализуется из обоих форматов; неизвестный тип не блокирует операцию.
- Установщик ссылался на удалённый `styles.css` и падал после копирования.
- `tools/install.ps1` сохранён в UTF-8 с BOM, чтобы Windows PowerShell 5.1
  корректно показывал русские сообщения.

### Добавлено

- `tools/test-command.js` — тест команд на моке Photoshop DOM.
- Проверка в `verify-offline.ps1`: список файлов установщика должен совпадать
  с содержимым `plugin/`.

## [1.1.0] — 2026-11-12

### Изменено

- Плагин переведён на две команды меню без панели и без интерфейса:
  «Выделить человека» и «Удалить фон».
- Удалены панель, `styles.css`, иконки и DOM-код.
- Ошибки показываются стандартным окном Photoshop (`app.showAlert`).
- Добавлена защита: если маска покрывает меньше 0,2 % кадра, команда ничего
  не меняет.

## [1.0.0] — 2026-11-12

### Добавлено

- Первый выпуск: офлайн-сегментация человека на CPU через onnxruntime-web
  (WebAssembly SIMD, один поток), модель MODNet.
- Fast guided filter на интегральных изображениях.
- Панель с режимами «Выделение» / «Маска слоя» и скоростью 384 / 512 px.
- Синхронная инициализация WebAssembly в обход падения Photoshop 2025.
