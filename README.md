# Fast AI Select

[![version](https://img.shields.io/badge/version-1.1.4-blue.svg)](../../releases)
[![license](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)

Офлайн-плагин для Adobe Photoshop 2025, который выделяет человека на фотографии
за одну команду. Нейросеть MODNet работает **на CPU через WebAssembly** внутри
UXP: без Python, без внешних `.exe`, без локального сервера и без интернета.
Видеопамять не используется вообще (0 МБ VRAM).

Плагин не имеет панели и вообще никакого интерфейса. В меню
`Плагины → Fast AI Select` есть ровно два пункта:

```
Выделить человека   → выделение человека
Удалить фон         → маска слоя: человек виден, фон скрыт
```

## Что внутри

- **Модель:** `modnet_photographic_portrait_matting.onnx` (24,7 МБ), 6,46 млн
  параметров, вход `[1, 3, H, W]`, выход — альфа-мат `[1, 1, H, W]`.
- **Движок:** `onnxruntime-web` 1.17.3, CPU/WASM, один поток, SIMD при поддержке
  процессора. Обе wasm-сборки лежат в `plugin/lib/`, ничего не скачивается.
- **Уточнение краёв:** fast guided filter на интегральных изображениях
  (subsample 4, радиус 8 px полного разрешения, eps 1e-4) плюс контраст мата
  вокруг 0.5. Радиус делится на коэффициент субдискретизации, поэтому край не
  «расплывается» на десятки пикселей; контраст убирает широкий полупрозрачный
  ореол вокруг одежды, сохраняя мягкость волос.
- **Автономность:** манифест не запрашивает ни сетевых разрешений, ни доступа к
  файловой системе. Модель и wasm читаются из папки плагина через
  `localFileSystem.getPluginFolder()`.

## Требования

- Windows 10/11 или macOS (сам плагин кроссплатформенный; `.bat`-установщик —
  только для Windows).
- Adobe Photoshop **26.0+** (2025). Проверено на 26.11.
- Процессор с WebAssembly SIMD (любой современный x86-64/ARM64). Без SIMD
  плагин тоже работает, но медленнее.
- UXP Developer Mode включён (нужен для внешних плагинов).

## Установка

### Вариант 1: установщик (Windows)

1. Закройте Photoshop.
2. Запустите `install.bat` двойным щелчком.
3. Перезапустите Photoshop.
4. Откройте `Плагины → Fast AI Select`.

Установщик копирует папку `plugin` в
`%APPDATA%\Adobe\UXP\Plugins\External\com.fastaiselect.panel_1.1.4`
и регистрирует плагин в `%APPDATA%\Adobe\UXP\PluginsInfo\v1\PS.json`.
Никакие другие файлы и настройки Photoshop не изменяются.

Удаление: `uninstall.bat` (или `tools\install.ps1 -Uninstall`).

### Вариант 2: UXP Developer Tool

1. Включите Developer Mode в UXP Developer Tool.
2. `Add Plugin…` → выберите `plugin/manifest.json`.
3. Нажмите `Load`, затем перезапустите Photoshop.

Это удобно для разработки: после правок достаточно нажать `Reload`.

### Вариант 3: простая копия

Скопируйте содержимое папки `plugin` в
`%APPDATA%\Adobe\UXP\Plugins\External\com.fastaiselect.panel_1.1.4`
и добавьте запись в `PS.json` (проще воспользоваться установщиком). Папка
самодостаточна: на другом офлайн-компьютере достаточно скопировать её целиком.

## Использование

1. Откройте фотографию в Photoshop (RGB, 8 или 16 бит/канал).
2. Активируйте слой, с которым будете работать.
3. Выберите команду в меню:
   - **`Плагины → Fast AI Select → Выделить человека`** — создаёт обычное
     выделение Photoshop. Дальше с ним можно работать как с любым другим:
     маска, корректировки, вырезание, `Ctrl+J`.
   - **`Плагины → Fast AI Select → Удалить фон`** — выделяет человека и добавляет
     маску слоя: человек остаётся видимым, фон скрывается. Пиксели не
     разрушаются, маску можно поправить кистью или применить навсегда
     (правый клик по маске → `Применить маску слоя`). Фоновый слой
     автоматически преобразуется в обычный, чтобы результат можно было
     свободно перемещать.

При первом запуске в текущем сеансе Photoshop модель загружается ~1 секунду,
поэтому первая команда выполняется немного дольше. Дальше сессия закэширована
до перезапуска Photoshop.

Если что-то не так (нет документа, слой заблокирован, слой не пиксельный,
человек не найден), плагин показывает обычное окно Photoshop с текстом ошибки.
Успешные операции ничего не выводят: результат виден сразу — «муравьи»
выделения или прозрачный фон.

### Скорость

Вход сети фиксирован: длинная сторона **512 px**, кратно 32. Это даёт более
детальный мат на волосах, чем 384. Если нужна максимальная скорость —
поставьте `SEGMENT_SIZE = 384` в `plugin/index.js`; если максимальная
детализация — `768` (примерно в 2,25 раза медленнее 512). Число должно быть
кратно 32.

Контраст мата задаётся параметром `sharpen` в `plugin/js/engine.js`
(по умолчанию `2`). Больше — жёстче край одежды и меньше ореола; меньше
(например `1.6`) — мягче волосы, но заметнее полупрозрачная кайма.

### Производительность

Замеры на тестовой машине (Node 24 / V8, тот же JS-движок, что и в UXP;
24 МП фото 4000×6000):

| Этап | Время |
| --- | --- |
| Нейросеть, 384 px (SIMD) | ~0,43 с |
| Нейросеть, 512 px (SIMD) | ~0,78 с |
| Guided filter, 12 МП | ~120–160 мс |
| Guided filter, 24 МП | ~230–300 мс |
| Загрузка модели + wasm + прогрев | ~1 с (один раз за сеанс) |
| Полное действие на 24 МП (512) | ~1,2–2,0 с |

Без SIMD нейросеть работает примерно в 3 раза медленнее. Первый запуск после
старта Photoshop может быть немного дольше: V8 прогревает JIT.

## Как это работает

```
┌─────────────────────────────────────────────────────────────┐
│ 1. executeAsModal: imaging.getPixels (RGB, 8 бит)           │
│    полный кадр читается один раз в Uint8Array               │
└───────────────────────────┬─────────────────────────────────┘
                            │  модальное окно закрывается
┌───────────────────────────▼─────────────────────────────────┐
│ 2. Box-resize до 512 (кратно 32), нормализация              │
│    (v / 255 - 0.5) / 0.5  →  Float32 NCHW [1,3,H,W]         │
├─────────────────────────────────────────────────────────────┤
│ 3. MODNet в onnxruntime-web (CPU, WASM SIMD, 1 поток)       │
│    сессия создаётся один раз и кэшируется глобально         │
├─────────────────────────────────────────────────────────────┤
│ 4. Fast guided filter по полному разрешению:                │
│    luma + альфа → интегральные изображения → a/b → q=a*I+b  │
│    радиус 8 px полного разрешения, затем контраст мата ×2   │
│    фон и внутренность заливаются 0/255, считается только    │
│    узкая полоса краёв                                        │
├─────────────────────────────────────────────────────────────┤
│ 5. Uint8-маска → createImageDataFromBuffer                  │
│    «Выделить человека»: putSelection                        │
│    «Удалить фон»: putLayerMask (белый = человек виден)       │
│    при недоступности маски — putSelection → inverse → delete │
│    imageData всегда освобождается                           │
└─────────────────────────────────────────────────────────────┘
```

Важные технические решения:

- **Обход падения Photoshop 2025 на WASM.** Нативный асинхронный
  `WebAssembly.instantiate()` после первого тика скрипта может уронить хост
  (`EXCEPTION_ACCESS_VIOLATION`). Поэтому `lib/ort.wasm.min.js` пропатчен:
  все вызовы `WebAssembly.instantiate` заменены на `__fasWasmInstantiate` из
  `js/wasm-env.js`, который синхронно делает `new WebAssembly.Module` +
  `new WebAssembly.Instance`. `fetch` для `.wasm` отвечает из памяти, без
  обращения к диску и сети. Модуль компилируется один раз.
- **Работа с выделением только через batchPlay.** В Photoshop 2025 DOM-API нет
  ни `Document.selection`, ни `Layer.clear()`, а `Layer.kind` приходит то
  числом (`1` = пиксельный слой, `12` = Background), то строкой (`"pixel"`).
  Поэтому тип слоя нормализуется из обоих форматов.
- **«Удалить фон» через маску слоя.** Основной путь — `imaging.putLayerMask`:
  белая маска оставляет человека, чёрная скрывает фон. Это не зависит от
  доступности пункта меню «Удалить» (в некоторых сборках Photoshop команда
  `delete` для выделения отвечает «в данный момент недоступна»). Если маска
  недоступна, включается резервный путь: `putSelection` → `inverse` →
  `delete` → `deselect`, разнесённый по отдельным модальным областям.
- **Три модальные области.** Проверка/разблокировка слоя, чтение пикселей и
  запись результата — отдельные `core.executeAsModal`. Нейросеть и guided
  filter работают вне модального окна, поэтому Photoshop не «замирает» на всё
  время расчёта.
- **Экономия памяти.** Полноразмерная float-альфа не создаётся: guided filter
  считает коэффициенты на сетке 1/4, а на полном разрешении выполняет только
  `q = a*I + b` в полосе краёв. Буфер RGB освобождается до записи маски.
- **Защита от ложного срабатывания.** Если маска покрывает меньше 0,2 % кадра,
  команда считается неудачной и ничего не меняет. Это не даёт «Удалить фон»
  очистить весь слой на фотографии без человека.

## Структура проекта

```
plugin/
  manifest.json          UXP v5, две команды, без панели
  index.html             порядок загрузки скриптов
  index.js               команды меню и сценарий действия
  guided_filter.js       fast guided filter
  js/core.js             resize, нормализация, маска → Uint8
  js/engine.js           ORT-сессия, MODNet, конвейер
  js/ps.js               Photoshop: пиксели, выделение, удаление фона
  js/wasm-env.js         синхронный WebAssembly + fetch-shim
  lib/ort.wasm.min.js    onnxruntime-web 1.17.3 (пропатчен)
  lib/ort-wasm-simd.wasm SIMD-сборка (используется по умолчанию)
  lib/ort-wasm.wasm      запасная сборка без SIMD
  lib/licenses/          лицензия ONNX Runtime (MIT)
  models/modnet.onnx     модель MODNet
  models/licenses/       Apache-2.0 текст и notice
tools/
  fetch-deps.ps1         скачать ORT + модель, пропатчить, проверить хэши
  patch-ort.js           патч WebAssembly-инстанцирования
  install.ps1            установка/удаление
  verify-offline.ps1     проверка комплектности и офлайн-режима
  package.ps1            сборка dist/*.zip
  test-core.js           тесты чистой логики + бенчмарки
  test-ort.js            сквозной тест ORT в эмуляции UXP
  test-command.js        тест команд на моке Photoshop DOM
install.bat / uninstall.bat
```

## Сборка зависимостей

Готовые файлы уже лежат в репозитории. Пересобрать их можно так:

```powershell
powershell -ExecutionPolicy Bypass -File tools\fetch-deps.ps1 -Force
```

Скрипт скачивает `onnxruntime-web@1.17.3` с npm и модель с Hugging Face,
распаковывает нужные файлы, применяет патч и сверяет SHA-256. Интернет нужен
только на этом шаге.

## Тесты

```powershell
node tools\test-core.js
node tools\test-ort.js
node tools\test-command.js
powershell -ExecutionPolicy Bypass -File tools\verify-offline.ps1
```

- `test-core.js` — ресайз, нормализация, guided filter (включая сверку с
  полным расчётом и бенчмарки 12/24 МП).
- `test-ort.js` — загружает настоящие wasm и модель в VM с моками UXP,
  проверяет синхронную инстанциацию, кэш сессии и полный проход
  «пиксели → маска».
- `test-command.js` — прогоняет настоящие `index.js` и `js/ps.js` на моке
  Photoshop DOM: регистрация двух команд, выделение, разблокировка фонового
  слоя, маска слоя для «Удалить фон», резервный путь через `delete`, а также
  защитные ошибки для заблокированного/непиксельного слоя и пустой маски.
- `verify-offline.ps1` — файлы, хэши, патч, манифест (ровно две команды, без
  панели), отсутствие неподдерживаемых DOM-вызовов, синтаксис JS.

## Упаковка

```powershell
powershell -ExecutionPolicy Bypass -File tools\package.ps1
```

Создаёт в `dist/`:

- `FastAISelect-1.1.4.zip` — плагин + установщик + документация;
- `FastAISelect-1.1.4-plugin.zip` — только папка плагина (manifest в корне);
- `SHA256SUMS.txt`.

## Автономность и приватность

- В манифесте нет `requiredPermissions`: сеть и пользовательские файлы
  недоступны.
- Изображение не покидает компьютер: нет HTTP-запросов, телеметрии и
  внешних процессов.
- Модель и wasm — обычные файлы в папке плагина.

## Ограничения

- Модель обучена на **портретных фотографиях людей**. На животных, товарах,
  еде и групповых снимках качество ниже; при нескольких людях выделяется
  самый заметный человек.
- «Удалить фон» работает с пиксельным слоем. Smart Object, текст и
  корректирующие слои нужно предварительно растрировать; заблокированные
  пиксели — разблокировать.
- «Удалить фон» добавляет маску слоя, а не стирает пиксели. Чтобы получить
  «жёсткий» результат, примените маску: правый клик по миниатюре маски →
  `Применить маску слоя`.
- Маска добавляется только на активный слой. Если фон находится на других
  слоях, они останутся нетронутыми.
- Очень большие документы (сотни мегапикселей) требуют много памяти: маска
  хранится как `Uint8Array` полного разрешения.
- Плагин не заменяет ручную доводку сложных краёв: выделение можно править
  стандартными инструментами Photoshop.
- UXP не поддерживает WebAssembly-потоки, поэтому расчёт всегда однопоточный.

## Диагностика

| Симптом | Что делать |
| --- | --- |
| `Не удалось загрузить onnxruntime-web` | Повреждена папка `lib/`. Переустановите плагин или выполните `fetch-deps.ps1 -Force`. |
| Photoshop падает при запуске команды | Проверьте, что `lib/ort.wasm.min.js` пропатчен: `verify-offline.ps1`. Не заменяйте файл на оригинал из npm. |
| `Файл models/modnet.onnx повреждён или отсутствует` | Модель не скопировалась. Переустановите плагин. |
| `Удаление фона работает только с пиксельным слоем` | Растеризуйте слой (`Слой → Растрировать`) и повторите. |
| `Слой заблокирован` | Снимите замок пикселей в панели «Слои». |
| `Человек на фото не найден` | Кадр не портретный или человек слишком мал в кадре. |
| Команды нет в меню | Закройте Photoshop, запустите `install.bat` заново и перезапустите Photoshop. Не устанавливайте плагин при работающем Photoshop — папка загруженного плагина заменяется, и он пропадает из меню. |
| Края одежды слишком размыты | Проверьте, что установлена 1.1.3+ (папка `com.fastaiselect.panel_1.1.4`): в 1.1.3 исправлен радиус guided filter и добавлен контраст мата. Ниже — `SEGMENT_SIZE = 384` для скорости, выше — `512`. |
| Волосы с белым ореолом на светлом фоне | Часть ореола — цвет самой фотографии (волосы сняты на белом). После «Удалить фон» примените `Слой → Обработка краёв → Удалить белый ореол`. |
| Плагин пропал из меню | Устанавливали при открытом Photoshop. Закройте его, запустите `install.bat` заново и перезапустите Photoshop. |
| Долгая первая команда | 26 МБ модели читаются с диска один раз; дальше сессия закэширована. |
| Нужны более точные края | Поставьте `SEGMENT_SIZE = 512` в `plugin/index.js`. |

Подробный лог выполнения пишется в консоль плагина — его видно в UXP Developer
Tool (`Console`).
